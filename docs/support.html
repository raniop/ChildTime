שאלות נפוצות

איך מחברים מכשיר של ילד?
במכשיר ההורה: כרטיס הילד ← "חברו את המכשיר" ← מוצג קוד QR. במכשיר הילד בוחרים "מכשיר של ילד" וסורקים את הקוד.

איך בוחרים אילו אפליקציות נחסמות?
בהגדרות ההורה ← בקרת המכשיר ← "אילו אפליקציות נעולות". נדרשת הרשאת Screen Time של Apple.

הילד הרוויח דקות אבל האפליקציות עדיין נעולות.
בדקו שהרשאת Screen Time אושרה במכשיר הילד, ושהמכשיר מחובר לאינטרנט. אפשר תמיד לפתוח זמן ידנית מהמכשיר שלכם: כרטיס הילד ← "תן דקות מתנה 💝".

שכחתי את קוד ההורה.
הקוד נקבע בכניסה הראשונה להגדרות. אפשר לאפס אותו דרך החשבון שאיתו נרשמתם, בהגדרות הורה ← קוד.

איך פותחים או סוגרים עולם לילד מסוים?
כרטיס הילד ← פעולות ← "העולמות של…". כל עולם נדלק ונכבה בנפרד לכל ילד.

איך מבטלים את המנוי?
הגדרות ה־iPhone ← השם שלכם ← מנויים ← טופי+ ← ביטול. הביטול נכנס לתוקף בסוף התקופה ששולמה.

איך מוחקים נתונים?
הגדרות הורה ← פרטיות ← מחיקת נתונים, או מחיקת ילד/ה מכרטיס הילד בלוח הבקרה. המחיקה מסירה את הנתונים גם מהענן.
