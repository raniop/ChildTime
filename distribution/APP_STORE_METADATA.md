### 2.1 / 1.3 — Reply to paste in App Review (and in App Review Information → Notes)
```
Does the app include third-party analytics?
No. The app collects/transmits no analytics. The Firebase Analytics SDK is intentionally not linked into the build (Kids Category); all analytics code paths compile to no-ops. GOOGLE_ANALYTICS_IDFV_COLLECTION_ENABLED = false and GOOGLE_ANALYTICS_DEFAULT_ALLOW_AD_PERSONALIZATION_SIGNALS = false.

Does the app include third-party advertising?
No. No advertising and no ad-network SDKs of any kind.

Will the data be shared with any third parties?
No data is shared with third parties for advertising, analytics, or tracking. The app uses Google Firebase (Authentication, Cloud Firestore, Cloud Messaging) solely as backend infrastructure to sync a child's learning progress across the family's own devices and deliver parent notifications. Access is restricted by security rules to the family's own account. We do not use IDFA/ATT and perform no cross-app tracking.

Is the app collecting any user/device data beyond analytics or advertising?
Yes — only what is necessary to operate the app, all family-scoped: parent account (email, display name, push token via Sign in with Apple/Google), child profile entered by the parent (nickname, approximate age band, optional gender, optional profile photo), and learning progress (topics practiced, accuracy, time, achievements). A randomly generated per-install UUID resolves cross-device sync conflicts. No location, no contacts, no IDFA, no birthdate. Supports COPPA/GDPR compliance for the Kids Category.
```
